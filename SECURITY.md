# Security Policy

## Supported Versions

Security updates and critical vulnerability patches are applied to the latest release:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `unity-openxr-starter` seriously. If you discover a security vulnerability, please do NOT open a public GitHub issue.

Please report vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/thesanketkale/unity-openxr-starter/security/advisories/new) or by emailing `sanket@sanketkale.com`.

### What to Include in Your Report

- Detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept code/project configuration.
- Potential impact on end users or standalone devices.
- Any suggested mitigations.

### Response Timeline

- **Initial Response:** Within 48 hours acknowledging receipt of the report.
- **Triage & Assessment:** Within 5 business days detailing validation results.
- **Patch Release:** Targeted within 14 business days depending on complexity.
